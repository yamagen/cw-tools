# CW methods restored in cw 0.9.0

`cw` now supports the historical `-M` calculation switch.

## Methods

### `-M 1`: basic CW

```text
CW_1(t1,t2;S,C)
  = (1 + ln(ctf_S(t1,t2)))
    * sqrt(idf_C(t1) * idf_C(t2))
```

This is the compact explanatory formula retained from cw 0.7.0.
Here, `ctf_S(t1,t2)` is the occurrence frequency of the pair `(t1,t2)` in
the selected unit set `S`, and `idf_C(t)` is the inverse document frequency
of pattern `t` in the complete input corpus `C`.  It can be used with or
without `-k`.

### Common notation

Let:

```text
C                  complete input corpus
N = |C|            number of units in C
S                  selected local unit set; S = C when -k is absent
df_C(t)            number of units in C containing pattern t
idf_C(t)           ln(N / df_C(t))
ctf_S(t1,t2)       total occurrence frequency of pair (t1,t2) in S
cdf_S(t1,t2)       number of units in S containing pair (t1,t2)
cdf_C(t1,t2)       number of units in C containing pair (t1,t2)
```

`cdf_S` and `cdf_C` are the same document-frequency measure evaluated over
different reference sets.  The subscript indicates whether the pair document
frequency is measured in the selected set `S` or in the complete corpus `C`.

### `-M 7`: waka-graph adjusted CW (default)

```text
CW = (1 + log10(ctf)) * sqrt(idf1 * idf2)
     --------------------------------------
              1 + log10(key_fq)
```

This restores the default formula from the earlier `cw.c`.
`key_fq` is the total local token frequency of all patterns matching the
`-k` regular expression inside the selected units.  For an exact key pattern,
it is the local frequency of that pattern.

The denominator is common to every pair in one key-selected graph.  It adjusts
the scale between graphs made from keys of different frequencies.  The use of
`log10` also makes the pair-frequency effect gentler than the basic formula's
natural logarithm.

### `-M 12`: rare-pattern experimental CW

```text
CW = (1 + key_fq / ctf) * sqrt(idf1 * idf2)
```

This restores historical method 12.  To reproduce the old C implementation,
`key_fq / ctf` is intentionally integer division before conversion to a
floating-point value.  It strongly rewards pairs that occur rarely inside the
key-selected set.

### `-M 16`: global-pair adjusted CW

```text
CW_16(t1,t2;S,C)
  = (1 + ln(ctf_S(t1,t2)))
    * sqrt(idf_C(t1) * idf_C(t2))
    * (1 + ln(N / cdf_C(t1,t2)))
```

This restores the structure of historical method 16, which was marked
`best` in the earlier source.  In the current notation, `ctf_S(t1,t2)` is the
local occurrence frequency of the pair in the selected set `S`, while
`cdf_C(t1,t2)` is the number of units in the complete input corpus `C`
containing that same pair.  Thus `N / cdf_C(t1,t2)` gives an inverse
document-frequency-like weight for the pair itself.  The division is computed
in floating point; the accidental integer truncation of the old C expression
is not reproduced.

The important distinction is one of reference set, not of frequency type:
`cdf_S(t1,t2)` and `cdf_C(t1,t2)` are the same pair document-frequency
calculation over `S` and `C`, respectively.  Method 16 uses the complete-corpus
value `cdf_C` in its global pair-weight term.

## Requirements

Methods 7 and 12 require `-k`, because their formulas contain `key_fq`.
They also require pair input containing token frequencies, generated by
`pair 0.2.0` or later.  Methods 1 and 16 accept the older three-column pair
format.  Method 16 may be used without `-k`; in that case `S = C`, so the local
and complete-corpus reference sets coincide.

## Examples

```sh
grep '^1' tests/data/hachidaishu-pair.txt |
  ./pair |
  ./cw -p 2,3 -k '^梅/名$' -M 7
```

```sh
grep '^1' tests/data/hachidaishu-pair.txt |
  ./pair |
  ./cw -p 2,3 -k '^梅/名$' -M 12
```

`-M 7` is the default, so the first command may omit `-M 7`.

```sh
grep '^1' tests/data/hachidaishu-pair.txt |
  ./pair |
  ./cw -p 2,3 -k '^梅/名$' -M 16
```
